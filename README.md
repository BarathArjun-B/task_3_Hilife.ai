# Tic Tac Toe (XO) Game Web App

This project is a responsive Tic Tac Toe (XO) Game developed using:

- HTML5
- CSS3
- Vanilla JavaScript

The game allows two players to play Tic Tac Toe with proper winner detection, draw handling, restart functionality, and responsive UI design.

---

# Features

- 2 Player Gameplay
- Player X and Player O Turns
- Winner Detection
- Draw Detection
- Restart Game Function
- New Game Reset
- Prevent Invalid Moves
- Winning Cell Highlight
- Responsive Design
- Hover Effects
- Smooth UI Interaction

---

# Game Rules

- Player X starts first
- Players take turns alternatively
- First player to match:
  - Row
  - Column
  - Diagonal
  wins the game
- If all cells are filled without a winner:
  Match becomes Draw

---

# Functionalities Implemented

## Winner Detection

The game checks all winning combinations after every move.

Example:
- Horizontal
- Vertical
- Diagonal

---

## Invalid Move Prevention

- Players cannot overwrite already selected cells
- Game stops after winner is found

---

## Restart Functionality

Restart button clears:
- Board
- Winner State
- Turn State
- Highlights
